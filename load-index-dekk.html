Vanlige spørsmål om load index dekk

Hvordan finner jeg load index på dekket mitt?

Load index står på sideveggen av dekket, rett etter dekkdimensjonen. For eksempel, i merking 205/55 R16 91V er tallet 91 load index. Det betyr at hvert dekk tåler 615 kg. Skriv inn nummeret i søkefeltet ovenfor for å slå opp bæreevnen med en gang.

Kan jeg bruke dekk med en annen load index?

Du kan bruke dekk med lik eller høyere load index enn det som er spesifisert for bilen din. Det er aldri lovlig eller trygt å bruke dekk med lavere load index, fordi det betyr at dekket ikke tåler vekten. Sjekk bilens brukerhåndbok eller dørkarmen for riktig load index.

Hvilken load index anbefales for min biltype?

Anbefalt load index avhenger av bilens vekt og bruk. Små personbiler bruker typisk 82–91, mellomklasse SUV-er 94–99, og store SUV-er eller varebiler 100–112. Sjekk alltid bilens typegodkjenning for riktig verdi. Bruk hvilke dekk passer min bil for mer informasjon om riktige dekk.
